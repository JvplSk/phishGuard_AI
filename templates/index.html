      04 / HOW IT WORKS

      Security analysis, without the black box.

      01

      Validate

      The backend safely parses the submitted URL and checks basic validity before analysis.

      02

      Extract

      PhishGuard measures HTTPS, IP usage, URL length, subdomains, keywords, shorteners and other structural indicators.

      03

      Classify

      Indicators are combined by an explainable risk engine to produce a threat level and supporting reasons.

      05 / PROJECT

      Built as a security engineering prototype.

      PhishGuard is a semester project by Krish & Swayam Koul. The architecture is designed so a trained dataset-backed ML classifier can be integrated without rebuilding the frontend.
