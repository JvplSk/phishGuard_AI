# PhishGuard
Functional Flask prototype for the AI-Based Phishing Website Detection semester project.

## Ubuntu
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 app.py

Open http://127.0.0.1:5000

Note: this starter uses explainable URL-feature scoring so it runs immediately. For the final project, replace/augment it with a trained ML model and a labeled phishing dataset.
